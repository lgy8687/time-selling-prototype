# 时间售卖 · 微信小程序演示版

版本：`v0.8.0-mini`。项目保留原有网页原型，小程序位于 `miniprogram/`，可用微信开发者工具导入。

## 本版体验

- 底部五个入口：大厅、时间表、发布、消息、我的。首页显示版本号与演示服务。
- 时间表有「月历＋安排」「月历＋时间块」两种排列。整页滚动时月历向当前周收拢；点日期更新下方内容，左右滑动月历切换月份，点月份返回当前月。时间块可切换全屏；小时可分成 `30+30`、`30+15+15`、`15+15+15+15`。
- 时间块按「选连续格 → 点右侧标签」记一条私人记录。一级标签下可设二级标签，例如课程与学员；设置页管理标签和显示时间，统计页按标签汇总次数与时长。
- 发布首页将「自己卖」与「我要求购」分组，组内显示对应的本机记录。售卖先选大类，再填写服务内容、履历、方式、地点和价格；可选指定售卖时间或日期范围内的空闲时间。开放售卖通过发布服务设置，不占用私人时间块。
- 大厅与「我发布的」共用服务详情。自有服务可在本机模拟买家预约：提交请求后，卖家在预约记录里确认，时间块随即显示买家称呼并可打开详情；未达最低人数的开团显示「待成团」。
- 「我的」提供发布、卖出、买到、可卖时间、时间块统计等入口；设置页可开启开发者模式。B 编号标识功能区，Z 编号标识操作，编号可点击复制，也可在设置中查阅。

## 演示范围

当前数据只保存在本机，包括预约请求和卖家确认。没有跨设备账号、跨用户实时库存、真实付款、真实消息或订单通知。示例服务只用于查看；正式交易需要服务端统一时间库存、状态和原子冲突检测。网页原型的本地数据不会自动导入小程序。

## 导入

在微信开发者工具中导入 `miniprogram/`。`project.config.json` 使用现有测试 AppID；正式发布前须换成主体对应的 AppID，并核对相关类目和审核要求。

交互编号登记在 `ui-registry.json`，小程序使用的副本在 `utils/ui-registry-data.js`。视觉延续网页原型的绿色、浅灰、亮黄与圆角卡片。
