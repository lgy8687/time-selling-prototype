# 时间售卖 · 微信小程序演示版

版本：`v0.1.0-mini`。这是在现有 React + Vite 原型旁新增的微信原生小程序，现阶段用于在微信开发者工具中体验和打磨时间表。网页原型仍在仓库根目录。

## 导入

1. 打开微信开发者工具，选择“导入项目”，目录选本文件夹 `miniprogram/`。
2. `project.config.json` 现使用开发者工具中已有的小程序测试号。需要正式发布时，须在开发者工具中替换为自己的正式 AppID。
3. 启动后进入“大厅”，底部可切换“大厅／时间表／发布／消息／我的”。

## 本版本能做什么

- 时间表按日查看，周和月用于选日期；每天可设置自己的显示起止时间。
- 每小时可选 `30+30`、`30+15+15`、`15+15+15+15` 三种分格。三格模式没有 20 分钟格。
- 常用标签在时间格右侧区域，可改成学生或小组名字。点标签再点格子添加时间，也可编辑标题、日期、起止时间和类型。
- 私人安排、已安排和开放时间共用本机事件集合；保存时检测冲突。可分享时间只展示未来且未与占用冲突的开放段。
- 发布页可保存本机服务草稿；大厅显示示例服务和本机草稿。我的页面可改昵称、上传本机头像，并查看草稿、开放时间及工具入口。

## 还没有接入

所有数据目前只保存在设备本地。没有登录、跨设备同步、跨用户发布、真实消息、支付或真实预约。大厅中的示例人物与价格不是可购买服务。正式预约需要服务端统一时间库存、订单状态和数据库事务；切勿把本机冲突检查当成防重复预约的服务端保障。发布草稿也不会在其他用户手机上出现。

网页原型的 `localStorage` 数据不会自动迁入微信小程序的本地存储。未来设计导入或迁移时，需要先做备份与数据映射。

## 维护

视觉使用原型中的绿色、浅灰、亮黄和卡片圆角。版本号显示在“我的”底部。`ui-registry.json` 登记 B/Z/C 交互编码；修改页面时同步更新登记，并运行 `node miniprogram/scripts/check-ui-registry.mjs` 巡检。

后续接入正式服务端时，建议按“账户与数据同步 → 时间库存及原子预约 → 公开发布和审核 → 交易与通知”的顺序推进。正式上线所需的主体资质、类目及交易规则应按届时微信官方要求核对。
