# 时间售卖 · 时间管理原型

版本：**v0.1.0**

这是一个独立 HTML 交互原型，用来体验个人时间管理、主动开放空闲时间、客户提交预约意向、提供者确认后占用时间的流程。售卖大厅在此版只是独立功能区的方向说明。

## 打开方式

发布后的网页地址：<https://lgy8687.github.io/time-selling-prototype/>

也可以直接打开仓库中的 `index.html`。

## 建议体验路径

1. 在“我的时间”添加已安排事项或私人占用。
2. 在“开放时间”主动选择一段无冲突的未来时间。
3. 在“客户视角”选择时段并提交预约意向。
4. 返回“我的时间”，确认或拒绝意向，观察课表与客户可见时间的变化。

页面显示运行版本号。点击“开发定位”可查看并复制 B/Z 交互编码；编码清单见 [交互编码.md](交互编码.md)。

## 演示边界

数据只保存在当前浏览器的 localStorage，不会上传到服务器。网页地址可以访问原型，但不同设备之间不会共享课表或预约意向；没有真实登录、支付、跨设备分享和服务端并发防重。请勿填写真实客户的联系方式或其他敏感信息。
